## What the gate caught that I would have shipped
Four rounds, sixteen findings, every one fixed rather than argued. The ones worth remembering:
- **Ordering beats intent.** My P0-I1 preflight was correct code in the wrong place: ESM evaluates static imports before any statement runs, so it guarded nothing. Then my first fix checked the kernel list against itself, which was circular. Only making the loader refuse uncleared files actually closed it.
- **A test that asserts the easy half hides the hard half.** My torn-tail test checked the returned sequence, not replay, so it passed while the recovering event was unreplayable.
- **A rule in prose is not a rule in code.** The live denominator's doc text said canonical production while the code compared target equality, and later still accepted `https://staging.acme.com` because `/` was not a token boundary.
- **A claimed fix is not a fix.** I reported CONVENTIONS.md corrected when the string replace had silently not matched, because I printed success unconditionally. Every edit now carries an assertion that fails loudly.
- **Honest backends can be rendered dishonestly.** The API returned `not_implemented`; the console rendered "empty"; the smoke certified it. Three layers of truthful-looking output over one lie.

## Process changes made
- No `git add -A` in a worktree with concurrent agents; stage explicit paths.
- No Phase N work on an unclosed Phase N-1 branch.
- Every scripted edit asserts its anchor.
- Prefer a deterministic script over a model dispatch whenever the output is a function of the input.
