## Local decision

Older research-first wording applies to generation from a brief. It does not
justify researching again when importing completed selected artifacts. A
selected transfer records provenance import as the pipeline research-stage
executor, skips copy/imagery/layout generation, and uses artifact composition
without byte rewriting. Explicit `package_existing` or `continue_build` intent,
origin, correlation and next action are mandatory. Rebuild is unsupported here
until a versioned reason and generation recipe exist. P0-I1 still protects the
three-concept ingress; no proof-route import is required for either origin.

1. Durable intake with exact payload hash, project/account/revision binding.
2. Verify artifact bytes and selected scope before repository writes.
3. Import provenance, package missing/changed bytes using foundation and DNA.
4. Validate local QA, protected review transport and signed callback separately.
5. Test restart, duplicates, wrong identities, changed bytes, retry and rollback.
6. Document external proof gaps and activation/rollback; stop before deployment.

The implemented continuation recipe is selected-html-slots-v1; package_existing
and continue_build no longer alias one another. No recipe means unsupported
continuation. General revision/application completion remains open.
